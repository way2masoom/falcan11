# TikTok LIVE Rewards Panel

A pixel-perfect clone of the TikTok LIVE Rewards and Coin Exchange interface with real-time profile lookups, interactive custom keypad, dynamic balance animations, and wallet customization settings.

## 🚀 Features
- **LIVE Rewards Dashboard**: Realistic hero balance display with dynamic coin equivalence and transaction logs.
- **TikTok Coin Exchange**: Interactive coin presets (250, 500, 15,000) and custom coin amount keypad sheet.
- **Live TikTok Profile Lookup**: Real-time username lookup with official TikTok avatar, creator nickname, and follower stats.
- **Confirmation Modal**: Split action buttons with official coin swirl animation.
- **Exchange Completed Receipt**: Green receipt statement with clean layout and transaction breakdown.
- **Wallet Settings (`⚙`)**: On-demand balance modification popup modal with license status.
- **Backend API**: Node.js Express server with live TikTok oEmbed and profile fetching.

## 🛠️ Getting Started

### Installation
```bash
npm install
```

### Run Locally
```bash
npm start
```
The app will be live at `http://localhost:3000`.

## 🌐 Deployment
This project is configured for instant 1-click deployment on **Vercel**, **Render**, or **Railway**.
